# RA.One Overdrive 🎮

A browser-based 2D fighting game built with pure HTML5 Canvas, CSS, and JavaScript — no frameworks, no libraries.

## Play Now
👉 [Click to Play](https://joker8946.github.io/ra-one-overdrive/)

## Features
- 1 Player vs Adaptive CPU (with Phase 2 boss mode)
- 2 Player local PvP
- Overdrive / Ultimate system
- Combo multipliers, shield & guard break mechanics
- Screen shake, hit pause, particle effects

## Controls
| Action | P1 | P2 |
|---|---|---|
| Move | A / D | ← / → |
| Jump | W | ↑ |
| Shield | S | ↓ |
| Dash | Shift | K |
| Blast | Space | L |
| Heavy | E | ; |
| Overdrive | Q | J |

HTML5 Canvas · Vanilla JavaScript · CSS3
